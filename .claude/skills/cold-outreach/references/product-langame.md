# Продукт: LANGAME для школ

Факты, на которые можно опираться в переписке. Всё в разделе «Проверено» взято из кода репозитория (`miniapp/src/SchoolsLanding.tsx` и корневой `/README.md`) на момент составления файла. Всё, что не перечислено здесь и не сказано пользователем, **выдумывать нельзя** — спроси или оставь плейсхолдер.

## Что это

Telegram-приложение для практики английского с AI-тьютором. Ученик занимается сам между уроками; школа получает кабинет преподавателя с картиной по каждому ученику. Весь AI-стек self-hosted, без внешних облачных API.

## Три боли, на которых построен оффер для школ

Формулировки с лендинга — их можно использовать дословно, они уже проверены на аудитории:

1. **«Никто не тренирует разговорный английский дома»**
2. **«Прогресс между уроками не виден»** — «„Занимался?“ — „Да“. Проверять некогда. Преподаватель узнаёт о пробелах только на занятии»
3. **«Ученики уходят, не увидев результата»**

Первая боль ближе учителю и методисту, вторая — методисту и завучу, третья — собственнику частной школы. Выбирай по роли получателя.

## Как устроено подключение

1. Школа оплачивает пакет — выбирает количество учеников и срок, платит картой, чек приходит на почту
2. Сразу после оплаты школа получает **ссылку-приглашение**, отправляет её ученикам в чат группы — двумя способами: через Telegram или через сайт
3. Ученики занимаются
4. Школа видит результат в кабинете преподавателя

Заявленное время подключения — **5 минут**. Ученику нужен Telegram или браузер.

## Кабинет преподавателя — главный аргумент для школ

| Функция | Формулировка с лендинга |
|---|---|
| Разбор ошибок учеников | По каждому ученику — частые ошибки за 30 дней в формате «было → стало». Готовый материал для урока |
| Отчёт в таблице | Выгрузка по всем ученикам за месяц одной кнопкой, открывается в Excel, подходит для отчётности |
| Лидерборд школы | Рейтинг учеников внутри школы |
| Управление составом | Ученик ушёл — отключаете его, место освобождается и достаётся новому. Пакет не пропадает |

«Разбор ошибок в формате „было → стало“» и «выгрузка в Excel» — два самых сильных пункта для государственных школ, потому что закрывают отчётность. «Управление составом» силён для частных: он снимает страх, что оплаченные места сгорят при оттоке.

## Что важно для юрлиц

- Оплата картой с чеком по **54-ФЗ**
- Можно **запросить счёт на юрлицо**, есть поле для пожеланий по договору
- Юрлицо: ООО «Скайрокет»
- Есть **бесплатный пробный период** (один на аккаунт)
- Есть возможность докупить места, если учеников стало больше
- Есть **доплата с ученика в месяц** как отдельная механика

## Отдельное преимущество: без рекламы ученикам

Формулировка с лендинга: «Ученикам школы сервис не предлагает купить личную подписку и не шлёт рекламных рассылок».

Это сильный аргумент именно для частных школ — он снимает главный скрытый страх директора: что вы подключитесь к его базе и начнёте уводить учеников на прямые продажи. Стоит проговаривать прямо, не дожидаясь вопроса — это классический приём «вырываем жало».

## Что умеет сам продукт (для аргументации методисту)

- **Разговор (voice)** — push-to-talk, живой диалог с мягким исправлением ошибок, перевод слова по тапу, объяснение исправлений
- **Чат (text)** — тот же тьютор текстом
- **Слушание** — генерация подкаста на 1/3/5/10/15 минут: уровень A2–C1, тема, скорость речи, опциональная вставка слов из личного словаря
- **Battle Mode** — дуэли между учениками с судейством
- **Удержание** — дневные квесты, стрики, медали, личный словарь, напоминания

Уровни A2–C1 — важная деталь для методиста: это язык, на котором он думает.
