# Учебная программа v1

Включается `LEARNING_ENABLED=true`; инструкция — [learning-deploy.md](learning-deploy.md).

После определения уровня пользователь выбирает цель. Сервер составляет
план следующего занятия и хранит материалы, ответы, диалог и текущий этап.
Существующие свободные режимы сохраняются. Уровень A1 поддерживается
в настройках разговора, грамматики и аудирования.

В каждом уроке: повторение слов → короткая теория → практика → аудирование
→ разговор → итог. Каждый пятый урок закрепляет материал. На каждое
двадцатое завершение приходится диагностика, затем доступен следующий
цикл. Верхний уровень C1 продолжает получать практику; число циклов не ограничено.

План использует 50 грамматических целей A1–C1 и 20 коммуникативных ситуаций.
Порядок ситуаций учитывает цель, повторения — результаты упражнений.
Контент учебного урока отделён от банка диагностических заданий. Готовые
материалы позволяют начать сразу. Фоновый работник может заменить их
свежим вариантом AI, пока урок ещё не начат; после старта материалы заморожены.
Уроки с ошибкой генерации продолжаются на готовом варианте.
Повторный тест уровня обновляет ещё не начатый материал; текущая практика
сохраняет свои задания. Изменение цели также учитывается при подготовке.

Статусы урока: `prepared`, `active`, `paused`, `completed`. Подготовка
не создаёт `sessions`. Начало создаёт одну родительскую `lesson`-сессию,
этапы отдельных сессий не создают. Сохранение и повторные запросы
идемпотентны. Потеря heartbeat приостанавливает урок примерно через
3 минуты, ответы и материалы сохраняются. Завершение атомарно записывает
прогресс, словарь, время и streak. Опыт начисляется за минуты урока один раз.

Бесплатный лимит определяется `settings_kv.free_lessons_per_day` (по
умолчанию 1), проверяется при начале целого урока. Начатый урок можно
продолжить. Подписка, welcome-trial и `FREE_PERIOD` учитываются существующим
механизмом доступа. Лимит не прерывает отдельные этапы.

Карта навыков использует первые ответы и последние наблюдения. Освоение
темы требует нескольких занятий; повторный ответ на тот же вопрос не
улучшает статистику. Для слуха нужны аудиоматериалы, текстовый вариант
исключается из этого показателя. Устная речь учитывается только после
серверного распознавания записи и успешной оценки AI. Оценка произношения
не реализована: модель получает расшифровку. При отсутствии данных
интерфейс показывает «Пока не оценено».

Новые события MyTracker: `course_started`, `lesson_started`,
`lesson_completed`, `checkpoint_started`, `checkpoint_completed`.
Они используют существующую транзакционную очередь и текущую Android
установку. Повторный HTTP-запрос не создаёт повторное событие. Обычный
`session_started` также отправляется один раз при начале полного урока.
Для рекламной оптимизации выбрать конкретное целевое событие.

Данные курса находятся в четырёх таблицах миграции 0043. Диагностика
сохраняется также в общей истории `level_tests` с `source=course`.
Сервер хранит идентификаторы вариантов; повторные формы избегают заданий
последних двух проверок. Измерение остаётся учебной диагностикой,
методическую оценку банка и разговорных критериев стоит провести в тестовом пилоте.

## Проверки разработки

Применить все миграции на отдельной локальной базе с суффиксом `_test`.
Затем из `backend`:

```bash
TEST_DATABASE_URL='mysql+asyncmy://englishbot@127.0.0.1:3307/englishbot_mytracker_test?charset=utf8mb4' \
MIGRATION_TEST_DATABASE_URL='mysql+asyncmy://englishbot@127.0.0.1:3307/englishbot_migration_test?charset=utf8mb4' \
python -m unittest discover -s tests -v
```

Вторая база должна быть отдельной и оканчиваться на `_migration_test`.
Проверки меняют её историю миграций и создают собственные тестовые строки.
Тесты курса проходят 20 реальных уроков через API, проверяют диагностику,
открытие следующего цикла, конкурирующие запросы, rollback, владельца,
квоты, приостановку и гонку генерации со стартом. Внешние AI/STT/TTS/S2S
в автоматических тестах подменяются.

Браузерные проверки требуют Playwright/Chromium и Vite с локальным API:

```bash
VITE_API_BASE=http://localhost:8082 npm --prefix miniapp run dev
# В другом терминале, из корня:
CHROMIUM_PATH=/usr/bin/chromium node --test scripts/test_learning_browser.cjs scripts/test_grammar_browser.cjs
node --test scripts/test_grammar_frontend.cjs scripts/test_mytracker_frontend.cjs
npm --prefix miniapp run build
npm --prefix admin run build
```

Строгие проверки типов:

```bash
cd miniapp && npx tsc -p tsconfig.app.json --noEmit
cd ../admin && npx tsc -p tsconfig.app.json --noEmit
```
